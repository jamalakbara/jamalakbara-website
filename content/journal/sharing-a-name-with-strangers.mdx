Search my name and you'll see the problem. Akbar is a very common name. Alam is a word. Plenty of people are called some version of Jamal Akbar. Google, reasonably, doesn't know which one you mean, and a portfolio that's only found when someone already knows the URL isn't doing its job.

So I treated my name as a small SEO problem and fixed it the way I'd fix a client's. This is what I did, in case yours needs the same.

## What I had before

Several names, used loosely. "Akbar" in conversation. "Jamal Akbar" in some places. A short handle, `jamalakbara`, on most platforms. A stage name, Chairil Akbar, which is real but isn't what I want to be known by professionally. Each was fine on its own. Together they split whatever search signal existed across several strings.

## The decision: one public name

I picked the full name, **Jamal Akbar Alam**, for everything identity-related: the site copy, structured data, keywords and the app manifest. "Akbar" stays for the casual first-person voice in posts, because that's how I actually talk. The wordmark is `jamalakbara.`, lowercase with the period, and that's the brand, not the name.

The rule is simple: formal places get the full name, conversation gets "Akbar", and nothing else gets invented.

## What the site now says, in machine terms

- **Person structured data** with the full name, so Google has an explicit statement of who this site is about.
- **Alternate names** listing the stage name, so someone who knows me by it still lands in the right place. Putting a stage name in as an alternate name is more honest than hiding it.
- **Links to my profiles** in the same data, so GitHub, LinkedIn and the rest are connected to the site by the site itself.
- **The same handle, `@jamalakbara`,** on every platform I use.

## What the site can't do alone

Here's the part I had to accept. More posts on my own site don't fix a shared-name problem. Search engines decide who a name belongs to by looking at the whole web: do profiles agree with each other, and do they point at each other? A site that says "this is me" and a profile that says something slightly different cancel each other out.

So the follow-up work is off-site and boring: the same bio, the same photo, the same name and a link back on every profile. That's a checklist, not a design problem.

## If you have a common name

1. Pick the single form you want to be found by, and use it everywhere formal.
2. Keep one handle across platforms.
3. Add Person structured data to your site with your real profiles in it.
4. Make every profile link to the site and the site link to them.
5. Write about things only you would write. A distinct body of work is the best disambiguator.
